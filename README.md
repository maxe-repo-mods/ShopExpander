# ShopExpander

Expands shop item variety. Configure max items per category and price multipliers.

R.E.P.O. BepInEx mod. Host-side only.

## Install

Requires [BepInEx 5.x](https://thunderstore.io/c/repo/p/BepInEx/BepInExPack/).

Place `ShopExpander.dll` in `BepInEx/plugins/`.

## Configuration

Edit `BepInEx/config/maxenterme.ShopExpander.cfg` after first launch.

## Build

```
dotnet build -c Release
```
